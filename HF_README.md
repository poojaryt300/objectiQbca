# ObjectIQ — Smart Object Detector 🔍

> **See it. Scan it. Identify it.**

An AI-powered object detection app using YOLOv8 + Streamlit.
Detects 80 common objects (people, laptops, phones, bottles, chairs, books, etc.)

**How to use:**
1. Click **Upload Image** → upload any photo → click **Detect Objects**
2. Or click **Camera Scan** → allow camera → take a photo
3. View results, confidence scores, bar chart, and download CSV

Built with Python · Streamlit · Ultralytics YOLOv8 · OpenCV · Plotly
